# NDB Opendata

NDBオープンデータ、スクレイピング＆ダウンロード in JavaScript/Deno

日本のNDB（レセプト情報・特定健診等情報データベース）オープンデータをスクレイピング、ダウンロード、処理するためのDenoスクリプト群です。

- **NDB**: National Database（ナショナルデータベース）。「高齢者の医療の確保に関する法律」に基づき、厚生労働省が医療費適正化計画の作成、実施、評価のための調査および分析等を行うために利用するデータベースです。

## データソース

- [【NDB】NDBオープンデータ｜厚生労働省](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177182.html)

## 特徴

- 厚生労働省のメインページをスクレイピングし、すべてのNDBデータリリースのインデックスを作成します。
- 各リリースページをスクレイピングし、すべての `.xlsx` ファイルのURLリストを取得します。
- すべての `.xlsx` ファイルをダウンロードし、リリース番号ごとにディレクトリに整理します。
- 複雑なマルチヘッダーのExcelファイルを、分析しやすいクリーンなCSVファイルに変換します。
- ダウンロードしたすべてのExcelファイル内からキーワードを検索するユーティリティスクリプトを提供します。

## 必要条件

このプロジェクトでは [Deno](https://deno.land/) を使用します。公式のインストール手順に従ってインストールしてください。

## 使い方

各スクリプトは、NDBオープンデータのローカルコピーを構築するために順番に実行するよう設計されています。`-A` フラグは、スクリプトの実行に必要な権限（読み取り、書き込み、ネットワーク）を付与します。

### 1. メインデータインデックスの作成

このスクリプトは、NDBオープンデータのメインページをスクレイピングし、利用可能なすべてのデータリリースを検索します。

```sh
deno run -A makeindex.js
```

これにより `ndb-opendata.csv` というファイルが作成されます。他のスクリプトで使用するために `index.csv` にリネームしてください。

```sh
mv ndb-opendata.csv index.csv
```

### 2. 詳細なファイルリストの生成

このスクリプトは `index.csv` を読み込み、各データリリースページをスクレイピングして、個々の `.xlsx` ファイルのリストを取得します。

```sh
deno run -A makecsv.js
```

これにより、各リリースに対応する複数のCSVファイル（例: `ndb-opendata-09.csv`）が生成されます。

### 3. すべてのExcelファイルのダウンロード

このスクリプトは、前のステップで生成されたファイルリストを読み込み、すべての `.xlsx` ファイルをダウンロードします。

```sh
deno run -A download.js
```

ファイルは `download/` ディレクトリに保存され、リリースIDごとのサブディレクトリ（例: `download/09/`）に整理されます。

### 4. ExcelからCSVへの変換

`xls2csv.js` スクリプトを使用して、ダウンロードした `.xlsx` ファイルをクリーンなCSVに変換できます。処理対象のファイルを指定するには、スクリプトを編集する必要があります。このスクリプトは、ヘッダーの再構築や値のフォーマットなど、大規模なデータクリーニングを実行します。

```sh
# xls2csv.js を編集して目的のファイルを指定し、実行します:
deno run -A xls2csv.js
```

クリーンアップされたCSVファイルは `data/` ディレクトリに保存されます。

### ユーティリティ: キーワードの検索

ダウンロードしたすべての `.xlsx` ファイルからキーワードを検索できます。デフォルトのキーワードは「糖尿病」です。

```sh
# デフォルトのキーワードで検索
deno run -A findXLS.js

# カスタムキーワード（例: "高血圧"）で検索
deno run -A findXLS.js "高血圧"
```

スクリプトは、一致したファイルのパス、シート名、およびメタデータを出力します。

## プロジェクト構成

- `/download`: 厚生労働省のウェブサイトからダウンロードしたオリジナルの `.xlsx` ファイルを保存します。
- `/data`: 処理およびクリーンアップされた `.csv` ファイルを保存します。
- `/temp`: ダウンロードしたHTMLページをキャッシュし、次回以降のスクリプト実行を高速化します。
